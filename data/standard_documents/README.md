# Dataset C — Project Reference ("Standard") Documents

These are **project reference templates written for LegalLens**. They are *not* official legal
standards, statutory forms or government-approved models. The comparison module labels them as
"Project reference template" everywhere in the UI and in the PDF report (guide section 15).

The values in them (for example 30 days' mutual notice, a liability cap equal to fees paid in the
last 12 months, a deposit of two months' rent) were chosen to reflect balanced, commonly used
drafting and — where a statute gives a benchmark — the statute cited in `data/legal_knowledge/`.

| File | Used for document type |
|---|---|
| standard_employment.txt | employment |
| standard_rental.txt | rental |
| standard_nda.txt | nda |
| standard_service.txt | service / business agreements |
